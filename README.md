# AAML2026 Lab Files

This repository is used to store the lab files for **AAML2026**.

Each lab has its own directory containing the files required for that lab:

```text
.
├── lab1/
├── lab2/
├── lab3/
├── lab4/
└── lab5/
```

* `lab1/` — Files for Lab 1
* `lab2/` — Files for Lab 2
* `lab3/` — Files for Lab 3
* `lab4/` — Files for Lab 4
* `lab5/` — Files for Lab 5

The corresponding files should be added to the appropriate location in the project directory according to the instructions.
